# 19. Anchor Consistency Rule

All screens generated after the three anchors must preserve:
- exact WeAreAiLabs logo
- white/off-white foundation
- brand teal/green/lime accents
- editorial serif + functional sans hierarchy
- quiet left navigation
- no decorative text at bottom of left rail
- restrained cards
- thin borders
- minimal shadows
- strong grid
- realistic content density
- functional use of color
- no generic AI visual tropes
