## 5. Global Navigation Recommendation

Primary learner navigation:

- Home
- Learn
- Workshops
- Community
- Projects
- Library

Secondary:
- Skills
- Certificates
- Profile

Instructor/Admin areas should be role-gated and visually separated from learner navigation.
